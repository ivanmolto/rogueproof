Documentation

Install Lumen Notes, create a vault and set up optional sync.

Install

Lumen Notes needs Node.js 20 or later.

npm install -g lumen-notes
lumen --version

Create a vault

A vault is an ordinary folder. Lumen adds a single .lumen/ directory for its search index and settings; everything else is your Markdown.

lumen init ~/notes
lumen new "Reading list"
lumen open

Commands

CommandWhat it does
lumen init <dir>Create a vault in a new or existing folder.
lumen new <title>Create a note and open it in your editor.
lumen search <query>Full-text search across the vault.
lumen links <note>List the notes that link to a note.
lumen syncPush and pull encrypted changes, if sync is configured.
lumen export --htmlRender the vault as a static site.

Configuration

Settings live in .lumen/config.toml inside the vault.

[editor]
command = "code --wait"

[search]
index_on_save = true

[sync]
enabled = false
remote = "https://sync.example.org/my-vault"
interval_seconds = 300

Sync

Sync is off by default. When enabled, notes are encrypted on your device with a key derived from your passphrase before they leave it; the server only ever stores ciphertext. You can run the reference sync server yourself or use any S3-compatible bucket.

Plugins

Plugins are small JavaScript modules loaded from .lumen/plugins/. They run in a sandbox with no network or file access unless the vault owner grants it. Plugin API v2, introduced in 2.4, adds custom views; see the changelog for migration notes.

Getting help

Run lumen help <command> for details on any command, or open a discussion on the project's issue tracker.
