Notes that stay yours

Lumen Notes is an open-source, local-first note-taking app. Your notes are plain Markdown files in a folder you choose; sync is optional and end-to-end encrypted.

npm install -g lumen-notes
lumen init ~/notes
lumen open
  • Plain MarkdownOne file per note. No database, no lock-in; any editor can open your vault.
  • Local-firstEverything works offline. Sync between devices when and if you want it.
  • Linked thinkingWiki-style [[links]], backlinks and a full-text search that indexes as you type.
  • Encrypted syncSelf-host the sync server or point Lumen at any S3-compatible bucket.
  • PluginsA small, sandboxed plugin API for commands, views and importers.
  • Apache-2.0Developed in the open by volunteers. Contributions welcome.

Who it is for

People who want a fast notebook that still works in ten years: researchers keeping a lab journal, engineers writing design notes next to their code, and anyone who has lost notes to a discontinued service.

Project status

The current stable release is 2.4.0. The desktop app runs on macOS, Windows and Linux; the command-line tool runs anywhere Node.js 20 or later does. See the changelog for what changed and the docs to get started.
